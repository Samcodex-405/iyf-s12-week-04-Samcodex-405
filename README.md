# Week 04 – JavaScript Fundamentals

Welcome to my **Week 04 project** for the **IYF WeCan Academy – Season 12 Practical Web Development Training**.

This week focused on building a foundation in JavaScript and understanding how it brings websites to life through programming logic, data manipulation and reusable functions.

## 📚 What I Learned

### Lesson 7: JavaScript Basics
- Variables (`let` and `const`) and data types.
- Arithmetic, comparison and logical operators.
- Functions, parameters and return values.
- Conditional statements and switch cases.
- Loops and control flow.
- Building a calculator using JavaScript functions.

### Lesson 8: Arrays & Objects
- Creating and manipulating arrays and objects.
- Working with array methods such as `map()`, `filter()`, `find()` and `reduce()`.
- Accessing and modifying object properties.
- Working with arrays of objects.
- Using JSON to represent and manipulate data.
- Building a student grade tracker.

## 🛠️ Mini Projects & Challenges

- **Calculator:** Performs arithmetic operations, including addition, subtraction, multiplication, division and modulus.
- **Student Grade Tracker:** Manages student records, calculates averages, identifies top performers and generates report cards.
- **Daily Challenges:** FizzBuzz, string reversal, finding the largest number, removing duplicates and palindrome checking.

## 💻 Technologies Used

- JavaScript (ES6+)
- HTML5
- Git & GitHub

## 🎯 Learning Outcome

This project strengthened my understanding of JavaScript fundamentals and improved my ability to solve problems using functions, loops, arrays, objects and logical expressions.

It marks another step in my journey towards becoming a confident web developer.
